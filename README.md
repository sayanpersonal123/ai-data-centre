# Inside an AI data centre

A 2.5 minute 3D film that follows electricity from the grid, through an NVIDIA GB200 NVL72 rack, down into a Blackwell GPU, and back out as heat.

**Watch:** https://sayanpersonal123.github.io/ai-data-centre/

- Single HTML file, no build step, no 3D assets. Everything is procedural Three.js (r128).
- Controls: Space pauses, arrow keys jump chapters, F goes full screen, H hides the controls, L toggles callouts.
- Frame presets for 16:9, 1:1, 4:5 and 9:16 so you can screen-record it for any platform.

Specs are NVIDIA-reported figures for B200 and GB200 NVL72. Facility values (voltages, generator timing, coolant temperatures) are typical, not a specific site.
